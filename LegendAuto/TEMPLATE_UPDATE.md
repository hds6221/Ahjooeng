# 템플릿 수정·항목 추가

## 프로젝트마다 명칭·규격만 다른 경우

템플릿을 고칠 필요가 없습니다. `LEGEND`에서 명칭·규격·수량 칸을 바로 고치고 도구 막대 **프리셋 저장(💾)**으로 다시 씁니다.

## 기호나 항목 자체를 추가하는 경우

**템플릿 DWG를 고쳐 저장하기만 하면 자동으로 반영**됩니다. 개발자 작업이나 다시 빌드할 필요가 없습니다.

1. `LEGEND` 창 왼쪽 아래 **[템플릿 수정]** 또는 명령 `LEGENDTEMPLATE` → `Template\범례템플릿.dwg`가 열립니다.
2. 넣을 공종 표에서 **맨 아래 행을 COPY**(기준점 → 450 아래)합니다. 여러 개를 넣으려면 450씩 더 아래로 복사합니다.
   - 표 안에 비어 있는 마지막 행이 있으면 그 칸에 바로 그려도 됩니다.
   - 중간에 끼워 넣어도 됩니다(아래 행들을 450씩 내리고 빈 자리에 넣기).
3. 기호와 글자를 고칩니다.
   - **구분** 칸: 기호(선·원·해치·블록 등)
   - **명칭 / 규격 / 단위 / 수량 / 비고** 칸: 글자(TEXT). 수량은 `-`로 둡니다.
   - 각 글자의 위치(삽입점)가 해당 칸 안, 해당 행 높이(450) 안에 있어야 합니다.
4. **저장(Ctrl+S)** 합니다.
5. 작업 도면에서 `LEGEND` → 명령줄에 `템플릿 변경을 반영했습니다: … 포장 9→10 …`이 나오고 목록에 새 항목이 생깁니다.

### 지켜야 할 것

| 항목 | 이유 |
|---|---|
| 표 외곽선(Defpoints 레이어 사각형)과 바탕 가림(WIPEOUT)은 지우지 않기 | 공종 표를 찾는 기준입니다. |
| 열 구분 세로선 5개와 제목·머리글 줄은 그대로 두기 | 칸 위치를 이 선으로 계산합니다. |
| 표 레이어 이름 `C-공종-범례…` 유지 | 레이어 이름으로 공종(우수·오수 …)을 구분합니다. |
| 행 높이 450 유지 | 행 번호를 450 간격으로 계산합니다. |
| 새 행은 표 바로 아래, 같은 열 범위 안에 | 외곽선 아래로 늘린 행도 같은 공종으로 인정합니다. |

테두리·세로선·가림 영역은 늘리지 않아도 됩니다. 범례를 생성할 때 고른 행 수에 맞춰 자동으로 늘이고 줄입니다.

### 반영되지 않을 때

- 명령줄의 `템플릿 주의:` 문구를 확인합니다. 예: `포장 11행: 명칭이 없어 등록하지 않았습니다.`
- **명칭 칸 규칙**: 새로 추가한 행은 명칭이 있어야 등록됩니다. 원래 표 안의 행이 명칭 칸만 비어 있고(위 행과 같은 이름을 생략한 경우) 기호·규격이 있으면, 목록에는 위 행 이름으로 보이지만 **도면에는 템플릿처럼 명칭 칸을 비워** 그립니다(예: 부대 32행 노면표시).
- 전체 분석 결과는 `%LOCALAPPDATA%\StormLegend\templates\<번호>\analysis-report.txt`에 있습니다.
- 템플릿을 읽지 못하면 이전에 성공한 템플릿으로 열리고 이유가 표시됩니다. DWG를 고친 뒤 다시 저장하세요.
- 템플릿을 저장하지 않았으면 반영되지 않습니다(명령줄에 알림).

### 프리셋

템플릿이 바뀌어도 저장된 프리셋은 기호 객체(DWG 핸들) → 기호 → 명칭·규격 순서로 같은 항목을 다시 찾습니다. 후보가 여러 개이거나 지운 항목은 자동으로 고르지 않고 빼며, 창을 열 때 "프리셋 다시 선택 필요"로 알려줍니다.

## 개발자 참고

- 분석기: `src/StormLegend/TemplateAnalyzer.cs`(예전 `tools/build_master_manifest.py` + `build_preview_catalog.py`를 C#으로 옮긴 것). 원본 DWG 분석 결과가 배포 `Template/categories/*.json`과 **완전히 같음**을 `verify.ps1`이 매번 확인합니다.
- 배포 `Template`의 JSON은 원본 DWG 해시(`catalog-index.json`의 `sourceDwgSha256`)가 같을 때 쓰는 미리 만든 분석본입니다. DWG가 바뀌면 `TemplateRepository`가 스냅샷을 복사해 분석하고 `%LOCALAPPDATA%\StormLegend\templates\<해시>`에 보관합니다.
- 배포본 자체를 새 템플릿으로 바꾸려면 새 분석 결과 폴더의 `catalog-index.json`, `categories`, `preview-catalog.json`, `source.dwg`를 검토한 뒤 `Template`에 반영하고 `verify.ps1`을 실행합니다(이때 원본 해시 검증 항목도 함께 갱신).

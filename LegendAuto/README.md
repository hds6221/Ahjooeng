# 통합 범례 AutoCAD 플러그인 1.0

AutoCAD 2020 · C# · .NET Framework 4.7.1 · x64

`범례템플릿.dwg`의 공사·유역·우수·오수·상수·포장·부대 표에서 필요한 항목만 골라 도면에 범례를 그립니다. 기호·레이어·글꼴은 템플릿 원본을 그대로 복사합니다. 생성 결과는 **블록이 아닌 개별 선·문자**입니다.

## 처음 설치

1. **AutoCAD를 닫고** `배포/Ahjooeng_v1.0_설치.zip`의 압축을 풉니다.
2. 풀린 폴더의 **`설치.bat`**을 두 번 클릭합니다. → `%APPDATA%\Autodesk\ApplicationPlugins\Ahjooeng.bundle`에 설치됩니다.
3. AutoCAD를 켜면 메뉴 막대에 **[Ahjooeng]**이 생기고 `LGD`가 바로 됩니다. **NETLOAD는 더 이상 하지 않습니다.**

- 지울 때는 `제거.bat`. 다시 설치하면 이전 설치본은 `ApplicationPlugins\Ahjooeng.previous-날짜…` 폴더로 최근 3개까지 남고, 설치 중 실패하면 이전 설치를 그대로 되돌립니다. 배포 전 개발판이 만든 `Ahjooeng.bundle.이전설치` 폴더가 있으면 직접 지워도 됩니다.
- 사용자가 고친 `범례템플릿.dwg`는 덮어쓰지 않고, 새 배포본을 `범례템플릿(새 배포본).dwg`로 옆에 둡니다.
- 예전에 `APPLOAD` → 시작하기 세트에 StormLegend.dll을 넣었거나 `bin\Release`를 NETLOAD하던 경우 빼 주세요(두 번 불러오게 됩니다).
- 개발 중 직접 불러올 때만 `NETLOAD` → `bin\Final\StormLegend.dll`(검증한 빌드)을 씁니다.

## 사용 순서 (`LEGEND`)

창은 [공용 화면 템플릿](../Shared/CadUi/README.md)으로 만든 1120×585 크기입니다. 위에서부터 **탭 → 도구 막대 → [원본 항목 | 선택 항목 | CAD 미리보기] → 아래 버튼** 순서입니다.

| 순서 | 할 일 |
|---|---|
| ① | 위쪽 **탭**(공사·유역·우수…)에서 공종을 고릅니다. 탭의 숫자는 고른 항목 수입니다. |
| ② | 왼쪽 **원본 항목**(기호·명칭·규격)을 클릭해 넣습니다. 다시 누르면 빠집니다. 검색칸으로 찾을 수 있습니다. |
| ③ | 도구 막대 **축척**에서 고르거나 입력합니다(`1:300` 또는 `300`). 1:100 = 기본 크기, 1:300 = 3배. |
| ④ | 오른쪽 아래 **[범례 생성]** → 도면에서 범례 **왼쪽 위 위치**를 클릭합니다. |

- 고른 공종이 여러 개면 **공사 → 유역 → 우수 → 오수 → 상수 → 포장 → 부대** 순서로 가로 한 줄로 그립니다. 비어 있는 공종은 건너뜁니다.
- 생성 직후 범례 전체가 선택되어 있어 바로 `MOVE`로 옮길 수 있습니다.
- 공종을 바꿔도 고른 내용은 그대로 남습니다. `Ctrl+1`~`Ctrl+7`로 공종을 바로 바꿀 수 있고, `Esc`로 닫습니다.

### 도구 막대

| 버튼 | 하는 일 |
|---|---|
| 불러오기 ▾ | 저장해 둔 구성이나 '전체 항목'을 불러와 선택 목록을 한 번에 채웁니다. |
| 저장 | 지금 선택·고친 명칭·수량·빈 행·순서를 이름 붙여 저장합니다. 다음 실행 때 이 구성으로 시작합니다. |
| 비우기 ▾ | 이 공종만 또는 모든 공종의 선택을 비웁니다. |
| 빼기 / 위로 / 아래로 | 가운데 표에서 고른 행을 빼거나(`Delete`) 순서를 바꿉니다. 범례도 이 순서로 그려집니다. |
| 빈 행 추가 ▾ | 공종 없이 빈 칸만 있는 행을 **고른 행 바로 아래(표 중간)** 또는 **맨 아래**에 넣습니다. |

가운데 **선택 항목** 표의 명칭·규격·수량 칸을 클릭해 고치고 Enter로 확정합니다. 고친 칸은 **초록 글자**로 보입니다. 표에서 **마우스 오른쪽 버튼**을 누르면 빼기·위로·아래로·빈 행 넣기·**원래 이름으로**(고친 명칭·규격 되돌리기)가 있습니다. 수량은 `-` 또는 0 이상 숫자입니다. 유역은 연결된 설명 도형이라 **한 세트**로만 넣습니다.

### 아래 버튼과 ⚙ 설정

**[템플릿 수정]** · **[설정]** · **[사용 방법]** · **[범례 생성]**

| 설정 | 내용 | 기본값 |
|---|---|---|
| ① 생성 형태 | **개별 선·문자로 그리기**(바로 고칠 수 있음) / **블록 하나로 묶기**(옮기기·지우기 쉬움, 고치려면 EXPLODE) | 개별 선·문자 |
| ② 공종 표 사이 간격 | 여러 공종을 가로로 늘어놓을 때 표 사이 간격(1:100 기준, 0~5000). 축척에 맞춰 함께 커집니다. | 300 |
| ③ 시작 축척 | 켜면 다음에 열 때 마지막으로 쓴 축척으로 시작합니다. | 끔(항상 1:100) |
| ④ 생성한 뒤 | 켜면 만든 범례를 선택된 상태로 둬서 바로 MOVE·COPY할 수 있습니다. | 켬 |

설정은 사람마다 `%LOCALAPPDATA%\StormLegend\settings.json`에 저장됩니다.

## 템플릿에 항목 추가 (`템플릿 수정` 버튼 / `LEGENDTEMPLATE`)

1. LEGEND 창 왼쪽 아래 **[템플릿 수정]**을 누릅니다. `Template\범례템플릿.dwg`가 열립니다.
2. 넣을 공종 표의 **맨 아래 행을 COPY로 450 아래에 복사**합니다. (표에 비어 있는 마지막 행이 있으면 그 칸을 바로 써도 됩니다.)
3. 기호를 그리거나 바꾸고 명칭·규격·단위·수량(`-`) 글자를 고칩니다. 글자는 각 칸 안에, 기호는 '구분' 칸 안에 둡니다.
4. 표 테두리·바탕은 늘리지 않아도 됩니다. 생성할 때 자동으로 맞춥니다.
5. **저장(Ctrl+S)** → 작업 도면으로 돌아가 `LEGEND`를 실행하면 새 항목이 목록에 나타나고 명령줄에 `포장 9→10`처럼 알려줍니다.

자세한 규칙과 주의 사항은 [TEMPLATE_UPDATE.md](TEMPLATE_UPDATE.md)를 보세요.

## 명령과 메뉴

AutoCAD를 켜면 메뉴 막대에 **[Ahjooeng]**이 생깁니다(리본은 쓰지 않음). 메뉴에는 **범례 생성 (LGD)**(누르면 바로 실행), **도움말**(명령 목록 → 명령을 누르면 사용 설명서), **프로그램 정보**가 있습니다. 나머지 명령은 명령줄이나 범례 창 버튼으로 씁니다. 메뉴가 안 보이면 `MENUBAR` → `1`, 사라졌으면 `AHJOOENGMENU`.

| 명령 | 메뉴 | 동작 |
|---|---|---|
| `LGD` / `LEGEND` / `STORMLEGEND` | 범례 생성 (LGD) | 화면에서 여러 공종을 골라 한 번에 생성 |
| `LEGENDALL` | — | 공종 번호와 축척을 입력해 한 공종 전체 항목 생성(수량 `-`) |
| `LEGENDORIGINAL` | — | 한 공종 원본 표를 병합 칸·빈 행까지 그대로 복사 |
| `LEGENDTEMPLATE` | — (창의 [템플릿 수정]) | 범례 템플릿 DWG 열기(항목 추가·수정) |
| `LEGENDSETTINGS` | — (창의 [설정]) | 생성 형태·공종 간격·시작 축척·생성 후 선택 |
| `LEGENDHELP` | — (도움말 목록의 범례 생성) | 그림으로 된 설명서([Help/index.html](Help/index.html)) 열기 |
| `AHJOOENGHELP` | 도움말 | Ahjooeng 도움말 홈(명령 목록) 열기 |
| `AHJOOENGINFO` | 프로그램 정보 | 버전·설치 위치·템플릿 상태·명령 목록 |
| `AHJOOENGMENU` | — | 메뉴 막대의 Ahjooeng 메뉴 다시 만들기 |

**사용 설명서:** 처음 쓰는 분은 [Help/index.html](Help/index.html)(창의 [사용 방법] 버튼과 같은 파일)을 보세요. 화면 그림에 번호를 붙여 설명합니다. 그림은 `verify-picker.ps1`을 실행하면 실제 화면으로 다시 만들어집니다.

## 안전장치

- 범례는 별도 임시 도면에서 완성한 뒤 한 번에 복사합니다. 중간에 오류가 나면 사용자 도면에 아무것도 남지 않습니다.
- 같은 도면에서 여러 번 생성해도 `$0$레이어` 같은 복제 레이어·블록이 늘어나지 않습니다. 도면에 같은 이름의 레이어가 이미 있으면 그 레이어를 씁니다. 레이어·선종류·문자 스타일 이름은 템플릿과 똑같이 들어갑니다.
- 선종류 무늬(예: U형측구 `U1`/`U2` 선)는 축척(1:300 등)과 작업 도면의 LTSCALE·주석 축척에 맞춰 선종류 축척을 조정해, 템플릿에서 보던 모양과 같게 그립니다.
- 템플릿 도면 자체에서 `LEGEND`를 실행하면 템플릿이 망가지지 않도록 멈춥니다.
- 열려 있는 템플릿을 저장하지 않았으면 명령줄에 알려줍니다.
- `FILEDIA`·`CMDDIA`는 **바꾸지 않습니다**(다른 스크립트가 일부러 0으로 둘 수 있음). 불러올 때 0이면 명령줄에 알려만 주고, `AHJOOENGDIA`로 1로 되돌립니다.
- 작업 도면에 템플릿과 이름은 같지만 내용이 다른 레이어·선종류·문자 스타일·블록이 있으면 ⚙ 설정 ⑤에 따라 **도면 정의 그대로 쓰기**(기본, 다른 점을 `확인:`으로 알림) 또는 **`이름_범례`로 따로 넣기**. 어느 쪽이든 기존 정의는 고치지 않습니다.
- 범례가 들어간 레이어가 꺼짐·동결·잠김·출력 안 함이면 `확인:`으로 알려줍니다(상태는 바꾸지 않음). 잠긴 레이어에도 생성은 됩니다.
- 복사 중 오류가 나면 이번에 넣은 객체·정의를 지우고 **원래 오류**를 보여줍니다. 단, AutoCAD가 지우지 못하게 하는 빈 `Defpoints` 레이어는 남을 수 있습니다(UNDO로 제거).
- 고친 템플릿을 읽지 못하면 **이 템플릿의** 마지막 정상 분석본(없으면 배포본)으로 열고 이유를 알려줍니다. `AHJOOENGINFO`에서 배포본·수정본·복구본 중 무엇을 쓰는지 볼 수 있습니다.
- 템플릿을 고쳐 행이 밀려도 프리셋은 **기호 객체(DWG 핸들)**로 같은 항목을 다시 찾습니다. 후보가 둘 이상(예: 명칭·규격이 같은 U형측구)이거나 확인할 수 없으면 **자동으로 고르지 않고** 그 항목만 빼고 "프리셋 다시 선택 필요" 창으로 알려줍니다. 이때 프리셋 파일은 고치지 않습니다.

저장 위치: 프리셋 `%LOCALAPPDATA%\StormLegend\presets-공종.json`, 고친 템플릿 분석본 `%LOCALAPPDATA%\StormLegend\templates\`(최근 5개).

## 빌드

필요: Windows x64, AutoCAD 2020(또는 2020 Managed SDK 참조 DLL), .NET SDK, NuGet `Microsoft.NETFramework.ReferenceAssemblies.net471` 1.0.3.

```powershell
.\build.ps1                                    # 플러그인
.\build.ps1 -AutoCADPath 'D:\Autodesk\AutoCAD 2020'
dotnet build .\StormLegend.sln -c Release -p:Platform=x64 -m:1   # 검증 도구 포함
.\verify.ps1          # AutoCAD Core Console에서 실제 생성 검증
.\verify-picker.ps1   # 숨긴 창으로 화면 검증 + 화면 이미지 저장
```

## 폴더

| 경로 | 내용 |
|---|---|
| `src/StormLegend` | 소스. `StormLegend.Core`(생성·템플릿 분석·선택 모델)와 `StormLegend`(화면·명령) |
| `Template` | 범례 템플릿 DWG와 분석된 연결 정보(JSON), 미리보기 도형 |
| `Help` | 그림 사용 설명서(index.html + images) |

| `tools` | 개발용: 원본 읽기 전용 내보내기, 예전 Python 매핑 도구(현재는 C# 분석기가 대신함), 배포 묶음 |

미리보기는 참고용입니다. 곡선 샘플링·글꼴 대체·해치 표시에 차이가 있을 수 있으며, 실제 도면에는 원본 객체가 그대로 복제됩니다. 원본에 쓰인 SHX 글꼴이 PC에 없으면 따로 설치해야 합니다.

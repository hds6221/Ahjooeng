범례 생성

공사·유역·우수·오수·상수·포장·부대 범례표에서 필요한 항목만 골라 도면에 한 번에 그립니다. 기호·레이어·글꼴은 범례 템플릿 원본을 그대로 씁니다.

처음 사용하기

  1. AutoCAD를 닫고, 받은 Ahjooeng_v1.0_설치.zip의 압축을 풉니다.
  2. 풀린 폴더의 설치.bat을 두 번 클릭합니다. "설치 완료!"가 나오면 Enter를 누릅니다.
  3. AutoCAD를 켜면 메뉴 막대에 Ahjooeng 메뉴가 생깁니다. Ahjooeng ▸ 범례 생성 (LGD)을 누르거나, 명령줄에 LGD(또는 LEGEND)를 입력합니다.
한 번만 설치하면 됩니다AutoCAD를 켤 때마다 자동으로 불러오므로 NETLOAD는 하지 않아도 됩니다. 지울 때는 같은 폴더의 제거.bat을 실행합니다. 예전에 APPLOAD → 시작하기 세트에 StormLegend.dll을 넣어 두었다면 빼 주세요(두 번 불러오게 됩니다).

메뉴 쓰는 법범례 생성 (LGD)을 누르면 바로 범례 창이 열립니다. 도움말을 누르면 명령 목록이 열리고, 거기서 범례 생성 (LGD)을 누르면 이 설명서가 나옵니다. 프로그램 정보에서는 버전·설치 위치·템플릿 상태를 봅니다. 앞으로 명령이 늘어나면 메뉴와 도움말 목록에 한 줄씩 추가됩니다.
참고메뉴 막대가 보이지 않으면 명령줄에 MENUBAR → 1을 입력합니다. 메뉴가 사라졌으면 AHJOOENGMENU를 입력하면 다시 생깁니다.

화면 구성

  • 1공종 탭 — 공사·우수 등 표를 고릅니다. 숫자는 고른 항목 수입니다.
  • 2원본 항목 — 템플릿에 있는 항목입니다. 클릭하면 넣고, 다시 누르면 뺍니다.
  • 3선택 항목 — 도면에 그려질 행입니다. 이 순서대로 그려집니다.
  • 4CAD 미리보기 — 그려질 모양을 미리 봅니다(참고용).
  • 5축척 — 1:100이 기본 크기, 1:300이면 3배로 그립니다.
  • 6범례 생성 — 누른 뒤 도면에서 위치를 클릭합니다.

4단계로 범례 만들기

  1. 공종 고르기 — 위쪽 탭에서 우수 등을 누릅니다.
  2. 항목 넣기 — 왼쪽 원본 항목에서 필요한 줄을 클릭합니다. ✓ 표시가 붙고 가운데 표에 들어갑니다. 다른 공종도 같은 방법으로 고릅니다.
  3. 축척 확인 — 도구 막대 축척을 도면 축척에 맞춥니다(목록에서 고르거나 1:300, 300처럼 입력).
  4. 생성 — 범례 생성 → 창이 닫히면 도면에서 범례의 왼쪽 위가 될 곳을 클릭합니다. 만든 범례는 선택된 상태라 바로 M(MOVE)로 옮길 수 있습니다.
참고여러 공종을 골랐으면 공사 → 유역 → 우수 → 오수 → 상수 → 포장 → 부대 순서로 가로 한 줄로 그립니다. 고르지 않은 공종은 건너뜁니다.

명칭·규격·수량 고치기

  1. 가운데 표에서 명칭·규격·수량 칸을 클릭합니다.
  2. 내용을 입력하고 Enter를 누릅니다. 미리보기에 바로 반영됩니다.
  3. 원래대로 돌리려면 행에서 마우스 오른쪽 버튼 → 원래 이름으로를 누릅니다(수량은 그대로).
주의수량은 - 또는 0 이상 숫자(정수 8자리, 소수 3자리)만 됩니다. 틀리면 창 아래에 빨간 글자로 이유가 나오고, 고칠 때까지 다른 공종으로 넘어가지 않습니다.

템플릿에 항목 추가

새 기호나 항목이 필요하면 템플릿 DWG에 한 줄을 추가하고 저장하면 됩니다. 프로그램을 다시 설치할 필요가 없습니다.

  1. 템플릿 수정(또는 LEGENDTEMPLATE)을 누르면 범례템플릿.dwg가 열립니다.
  2. 넣을 공종 표의 맨 아래 행을 COPY로 450 아래에 복사합니다.
  3. 복사한 행의 기호와 글자(명칭·규격·단위)를 고칩니다. 수량은 -로 둡니다.
  4. Ctrl+S로 저장하고, 작업 도면으로 돌아가 LGD를 실행합니다. 명령줄에 포장 9→10처럼 반영 결과가 나옵니다.

문제 해결

메뉴 막대에 Ahjooeng이 없어요

MENUBAR → 1로 메뉴 막대를 켜고, 그래도 없으면 AHJOOENGMENU를 입력합니다.

템플릿에 추가한 항목이 안 보여요

템플릿을 저장했는지 확인하세요. 명령줄의 템플릿 주의: 문구에 이유가 나옵니다(예: 명칭 칸이 비어 있음).

NETLOAD 때 파일 선택 창 대신 명령줄로 물어요

FILEDIA·CMDDIA가 0인 경우입니다. 다른 자동화 도구가 일부러 0으로 둘 수도 있어 이 프로그램은 값을 바꾸지 않고, AutoCAD를 켤 때 명령줄에 알려만 줍니다. 파일 선택창을 다시 쓰려면 명령줄에 AHJOOENGDIA를 입력하세요.

"템플릿을 읽지 못해 … 마지막 정상 분석본으로 엽니다"가 나와요

고친 템플릿 DWG를 읽을 수 없는 상태입니다(저장 중이었거나 표가 손상됨). 이 템플릿이 마지막으로 정상이던 때의 내용으로 열었으니 새로 고친 항목은 빠져 있습니다. 템플릿을 다시 열어 저장한 뒤 LGD를 다시 실행하세요. AHJOOENGINFO에서 지금 쓰는 템플릿이 배포본·수정본·복구본 중 무엇인지 볼 수 있습니다.

"프리셋 다시 선택 필요" 창이 떠요

템플릿이 바뀌어 저장해 둔 프리셋의 일부 항목이 어느 항목인지 확실하지 않은 경우입니다(예: 명칭·규격이 같은 U형측구가 두 개). 엉뚱한 기호에 수량이 붙지 않도록 그 항목만 빼고 열었습니다. 다시 골라 [저장]하세요.

생성한 범례 글자가 다른 모양으로 보여요

템플릿에 쓰인 글꼴(SHX 등)이 이 PC에 없으면 다른 글꼴로 보입니다. 같은 글꼴 파일을 설치하세요.
